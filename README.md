# 🏢 Dwelio Frontend

An innovative mobile and web application interface built with React, Ionic, and Capacitor.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Make sure you have Node.js installed on your machine. You can download it from [nodejs.org](https://nodejs.org).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project folder:
   ```bash
   cd dwelio-frontend
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running the App

To launch the local development server and view the application in your browser:
```bash
npm run dev
```

## 📱 Mobile Deployment (Capacitor)

This project uses Capacitor to bridge web code to native applications.

* **Open Android Studio project:**
  ```bash
  npx cap open android
  ```
* **Sync web assets to native code:**
  ```bash
  npx cap sync
  ```
